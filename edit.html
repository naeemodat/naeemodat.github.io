Edit site updates

Change the schedule and announcements below, then copy the result into data.json on GitHub. Nothing is published until you commit it there.

How to publish
  1. Edit the fields below, then press Copy JSON.
  2. Open data.json in your GitHub repository and press the pencil (edit) icon.
  3. Select all, paste, then press Commit changes. The site updates within a minute or two.

Semester label

Weekly schedule

One row per session. Use 24-hour times, for example 13:00. Type controls the color: class, lab, or office hours.

Announcements
